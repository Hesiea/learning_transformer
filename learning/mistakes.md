> 用途：记录**你曾经想错的地方**。这是整个学习档案里信息密度最高的文件——
> 因为它记录的不是「知识」，而是「你的心智模型与真实情况的偏差」。
>

### 示例（供参考格式，不是你本人的错题）

#### 错误理解 0 ｜ 2026-09-13 ｜ KV Cache 的等价性不是自动成立的

- **我原以为**：只要把历史的 K/V 缓存起来，逐 token 推理就必然等价于全量前向
- **实际是**：等价性依赖两个容易漏掉的细节 ——
  (1) 位置嵌入必须按**绝对位置**取（`pos_offset`），否则喂进去的向量与全量路径不一致；
  (2) 掩码必须按 query 的真实位置对齐，不能直接用 `is_causal=True`
  （单 query + 多 key 时 SDPA 会按左上角对齐，把全部历史当成未来屏蔽掉）
- **为什么我会想错**：把「缓存」理解成了纯工程优化，忽略了它同时改变了**位置语义**
- **怎么验证的**：工程里 `tests/test_common.py` 的 KV Cache 等价性测试；
  以及实测两条生成路径逐 token 比对（不同位置数必须为 0）
- **教训**：任何「等价变换」都要写出它依赖的前提，然后用数值验证，不能靠推理相信
- **重考安排**：不需要（这是 Agent 侧的 bug 记录，非学员错题）
